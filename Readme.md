# Canary Brain 

es un programa usado para aplicar la tecnica de spaced repetition
su objetivo es tomar las notas del usuario y resumirlas en preguntas que se realizaran en un tiempo determinado
los objetivos del proyecto son:
>- sumarizacion de apuntes
>- generacion de preguntas de los apuntes
>- generacion de un sistema de progreso (usando el que se describio en htb)


# sistema de proreso de una tarea

1) primero se debe hacer una lsta donde se escriba nuestra fecha actual y todo lo relacionado a lo que sabemos sobre nuestro tema a alcanzar con todas las skills necesarias que deberiamos contemplar de un 1 al 10 la aplicacion debera proporcionar una pre lista buscando en internet

2) la lista continua se actualizara apenas se haya familiarizado con una habilidad de un tema que hayamos aprendido 

la aplicacion al apenas cargar un documento debera registrar en la lista inmediata esta habilidad y permitir la eliminacion del punto si no se quiere
